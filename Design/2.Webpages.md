## Webpages

```
         (1)
WebHome -->-- WebCollections 
                  |     
                  +-->-- WebCollectionNew  
                  |
                  +-->-- WebCollectionEdit
                  |
                  +-->-- WebCollectionDashboard


(1) user logs.in

```


## WebHome
Public mainpage
- user login
- quick-demo with video or images or explanation
- link to public docs

## WebCollections
Once user logs in
- Table showing all collections belonging to the user
  - One collection per line, with:
    - collection name (link'ed to **WebCollectionDashboard**)
    - resume of last CollectionRevision: creation-date, modification-date, RevState, last-modified-by user
    - button "Edit Collection" leading to **WebCollectionEdit** enabled or disabled   
      If Collection.IsEditable() == false, then show button disabled
  - opHub.CollectionsListOfUser() returns the list of collections for this user
- Button "New collection" (leading to **WebCollectionNew**)

## WebCollectionNew
When user wants to create a new collection
- Ask user:
  - CollectionName
  - Collection Description
  - AdmissionPolicy: AdmissionPolicyParams
    - AdminUsers
    - AdminGroups
    - ReaderUsers
    - ReaderGroups
- Button "Create"
  - send message to server, to create the new collection and get back a response with Completed/Failed
    - Response with Completed: should send back and show user collectionID and CollectionName. Then redirect to **WebCollectionEdit**
    - Response with Failed: should send back error and show user error. Then redirect to **WebCollections**
  - opHub.CollectionNew() intents to create a new collection
- Button "Cancel" 
  - redirect to **WebCollections**

## WebCollectionEdit
When user wants to edit a collection
- Start the editing of a collection
  - client opens websocket, exchange ws-messages with server to reqquest/reply needed data
  - opHub.CollectionEditOngoing() - at start of editing
  - user edits the form data, which might trigger ws-messages for server to execute blueprint-processes 
  ...
- Button "Save"
  - ...
  - opHub.CollectionEditCompleted()
- Button "Cancel"
  - ...
  - opHub.CollectionEditCancelled())

## WebCollectionDashboard
When user wants to see the details of a collection
- Info from last **CollectionRevision**: last-modification date, user, RevState
- History of previous **CollectionRevision(s)** with dates, user, RevState - in descending order (latest on top)
