
## Concepts internals

```
  Collection
    - has zero-or-more CollectionRevision(s)

  
  CollectionRevision
    - has one-or-more RevState(s)


```


### Collection
- **CollectionID**
- **CollectionName**
- **_collectionRevisions** - internal field, not for direct access, use its own getter funcs instead
- **CollectionRevisions() []CollectionRevision** - only func that can set/upd/get _collectionRevisions


- **CollectionRevisionLatest()**: latest **CollectionRevisions()** element
- **CreationDate()**: return **CollectionRevisionLatest().CreationDate**
- **ModDate()**: return **CollectionRevisionLatest().ModDate**
- **IsRevStateEditable()**: boolean - return **CollectionRevisionLatest().IsRevStateEditable()**
- **RevStateLatestName()**: return **CollectionRevisionLatest().RevStateLatestName()**

- **CollectionRevisionAppend(newCollectionRevision)**: 
  - read CollectionRevisions(), append the new **CollectionRevision**, save to db

### CollectionRevision
- **RevID**
- **_revState []RevState** - internal field, not for direct access, use its own getter funcs instead
- **RevStates() []RevState**: only func that can set/upd/get _revState
    RevStates flow diagram:
    ```
        CollectionEditOngoing   ------->  CollectionEditCancelled     
            v
        CollectionEditCompleted
            |
            v
        ProvisionOngoing        ------->  ProvisionFailed
            v
        ProvisionCompleted
    ```
- **RevStateLatest()**: return latest **RevState**
- **CreationDate()**: return **RevStates()[0].CreationDate**
- **ModDate**: return **RevStateLatest().CreationDate()**
- **IsRevStateEditable()**: return **RevStateLatest().IsRevStateEditable()**
- **RevStateLatestName()**: return **RevStateLatest().RevStateName**

- **RevStateAppend(newRevState)**: 
  - validate state transition from current **RevState** to the new **RevState** is allowed
  - read RevStates(), append the new **RevState**, save to db

### RevState

#### RevStateCollectionEditOngoing
- embed **RevStateBase**
- **UserWhoInitiated**: **User**

 - **NewRevStateCollectionEditOngoing(...)**


#### RevStateBase
- **RevStateID**
- **CreationDate**
- **RevStateName** one of:
    - `CollectionEditOngoing`:   The collection edit is ongoing 
    - `CollectionEditCancelled`: The collection edit has been cancelled
    - `CollectionEditCompleted`: The collection edit has completed successfully
    - `ProvisionOngoing`:        The provisioning of the selected products is ongoing.
    - `ProvisionFailed`:         The provisioning of the selected products has encountered an error and did not complete successfully.
    - `ProvisionCompleted`:      The provisioning of the selected products has completed successfully.
 - **IsRevStateEditable**: boolean - can the collection be edited while in this state, or not
