
## Concepts internals

```

  Collection
    + has 1 AccessPolicy (1Collection-to-1AccessPolicy)
    + has zero-or-more ColRevision(s) (1Collection-to-manyColRevision)
    . Logic:
      . When new collection is created, it has empty ColRevisions[] 
      . When user initiates a CollectionEdit, then Collection creates a new ColRevision (with initial RevState "CollectionEditOngoing")
      . A CollectionEdit can only start if Collection.IsEditable()==true (.IsEditable() comes from ColRevision->RevState) 

    . Logic:
      . When new collection is created, it creates an initial ColRevision  with RevState "Ready".
        So ColRevisions[] is never empty and GetColRevisionLatest always returns a valid ColRevision
      . When user initiates a CollectionEdit, then Collection creates a new ColRevision (with initial RevState "CollectionEditOngoing")
      . A CollectionEdit can only start if Collection.IsEditable()==true (.IsEditable() comes from ColRevision->RevState) 


  ColRevision
    + has one-or-more RevState(s) (1ColRevision-to-manyRevState)

  RevState
   
```

### Collection

+ **CollectionLoad(...)**

+ **.GetCreationDate()**             
+ **.GetModDate()**:                  return **ColRevisionLatest().GetModDate**

### ColRevision
+ **ColRevisionNew(...)**
+ **ColRevisionLoad(...)**

+ **GetID()**        "ColRevID-<DbColRevision.ID>" 

+ **GetCollectionID()**  CollectionID   1Collection-to-manyColRevision

+ **GetRevStates() []RevState**
+ **GetRevStateLatest()**:         return latest **RevState**
+ **GetRevStateLatestName()**:     return **GetRevStateLatest().RevStateName**
+ **AppendRevState(newRevState)** 
+ **GetCreationDate()**:           return **GetRevStates()[0].GetCreationDate**
+ **GetModDate()**:                return **GetRevStateLatest().GetCreationDate()**
- **IsEditable()**:                return **GetRevStateLatest().IsEditable()**


### RevState
```
RevStates flow diagram:

	A ColRev-N starts from the ColRev-N-1 "Ready", and then follows transitions which finally ends-up in either "Ready" or "ErrorZZZZ"
	A ColRev-N+1 can only start from a "Ready"-ColRev-N but cannot start from a "ErrorZZZZ"-ColRev-N
  All ColRev-N terminate in either "Ready" or "ErrorZZZZ"

	_ColRev-N-1_ ___________ ColRev-N ______________________________________________

	Ready ___                                                                  Ready
	         \__                                                                 A
	            v                                                                |
	             CollectionEditOngoing   --->  CollectionEditCancelled  >------->+
	                   v                                                         |
	             CollectionEditCompleted                                         |
	                   |                                                         |
	                   v                                                         |
	             ProvisioningOngoing     --->  ErrorProvisioningFailed           |
	                   v                                                         A
	             ProvisioningCompleted   >-------------------------------------->+

```



#### RevStateCollectionEditOngoing
// common fields for all RevStates
- **RevStateID()**    "RevStateID-<DbRevState.ID>"
- **GetCreationDate()**
- **RevStateName()** one of:
    - `Ready`: The collection is ready for use
    - `CollectionEditOngoing`:   The collection edit is ongoing 
    - `CollectionEditCancelled`: The collection edit has been cancelled
    - `CollectionEditCompleted`: The collection edit has completed successfully
    - `ProvisioningOngoing`:        The provisioning of the selected products is ongoing.
    - `ErrorProvisioningFailed`:         The provisioning of the selected products has encountered an error and did not complete successfully.
    - `ProvisioningCompleted`:      The provisioning of the selected products has completed successfully.

// specic fields for this RevState
- **UserWhoTriggered()**: **string with user-name**
