
## Concepts internals

```

  Collection
    - has zero-or-more CollectionRevision(s) (1Collection-to-manyCollectionRevision)
    - has 1 AccessPolicy (1Collection-to-1AccessPolicy)

  CollectionRevision
    - has one-or-more RevState(s) (1CollectionRevision-to-manyRevState)


```


### AccessPolicy: 
- 2 roles Admin or Reader
type User string
type Group string

+ **GetID()**  "AccessPolicy-<DbAccessPolicy.ID>"
+ **GetCollection()**  *Collection
+ **GetAdminUsers() []User**
+ **SetAdminUsers(users []User)**
+ **GetAdminGroups() []Group**
+ **SetAdminGroups(groups []Group)**
+ **GetReaderUsers() []User**
+ **SetReaderUsers(users []User)**
+ **GetReaderGroups() []Group**
+ **SetReaderGroups(groups []Group)**
+ **IsAdmin(some_user User, some_groups []Group) bool**
+ **IsReader(some_user User, some_groups []Group) bool**

+ NewAccessPolicy(collection *Collection, adminUsers, adminGroups, readerUsers, readerGroups []string) (*AccessPolicy, err)
+ LoadAccessPolicy(AccessPolicyID string) (*AccessPolicy, err)


### Collection
+ **.GetID()**  "ColID-<DbCollection.ID>"
+ **.GetName()**
- **.CollectionRevisions() []CollectionRevision**
- **.GetAccessPolicy()**   AccessPolicy

- **.CreationDate()**:             return **CollectionRevisions()[0].CreationDate**
- **.ModDate()**:                  return **CollectionRevisionLatest().ModDate**
- **.IsEditable()**: boolean -     return **CollectionRevisionLatest().IsEditable()**
- **.RevStateLatestName()**:       return **CollectionRevisionLatest().RevStateLatestName()**

- **.CollectionRevisionAppend(newCollectionRevision)**: 
  - read CollectionRevisions(), append the new **CollectionRevision**, save to db

### CollectionRevision
- **RevID()**        "ColRevID-<DbCollectionRevision.RevCounter>"  1,2,3,4 for each collection
- **RevStates() []RevState**
    RevStates flow diagram:
    ```
        CollectionEditOngoing   ------->  CollectionEditCancelled     
            v
        CollectionEditCompleted
            |
            v
        ProvisioningOngoing        ------->  ProvisioningFailed
            v
        ProvisioningCompleted
    ```
- **RevStateLatest()**:      return latest **RevState**
- **CreationDate()**:        return **RevStates()[0].CreationDate**
- **ModDate()**:               return **RevStateLatest().CreationDate()**
- **IsEditable()**:          return **RevStateLatest().IsEditable()**
- **RevStateLatestName()**:  return **RevStateLatest().RevStateName**

- **RevStateAppend(newRevState)**: 
  - validate state transition from current **RevState** to the new **RevState** is allowed
  - read RevStates(), append the new **RevState**, save to db

### RevState

#### RevStateCollectionEditOngoing
// common fields for all RevStates
- **RevStateID()**    "RevStateID-<DbRevState.ID>"
- **CreationDate()**
- **RevStateName()** one of:
    - `CollectionEditOngoing`:   The collection edit is ongoing 
    - `CollectionEditCancelled`: The collection edit has been cancelled
    - `CollectionEditCompleted`: The collection edit has completed successfully
    - `ProvisioningOngoing`:        The provisioning of the selected products is ongoing.
    - `ProvisioningFailed`:         The provisioning of the selected products has encountered an error and did not complete successfully.
    - `ProvisioningCompleted`:      The provisioning of the selected products has completed successfully.
- **IsRevStateEditable()**: boolean - can the collection be edited while in this state, or not  

// specic fields for this RevState
