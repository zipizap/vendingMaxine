
## Concepts internals

```
  Team
    - has zero-or-more Collection(s) (manyCollection-to-1Team)

  Collection
    - has zero-or-more CollectionRevision(s) (1Collection-to-manyCollectionRevision)
    - has 1 Team (manyCollection-to-1Team)

  CollectionRevision
    - has one-or-more RevState(s) (1CollectionRevision-to-manyRevState)


```

### User, Group
  - User and Group are very similar.
  - User should be a "ghost" object - it does not store data, only reads jwt fields and presents them via its methods
  - Other objects can store User.uniqueID to reference a specific user. So only the uniqueID is stored in db, on objects that need to reference users
#### User
  - **Name()** 
  - **Email()**
  - **uniqueID()** field fom jwt that uniquely identifies the user (?jwtSub?)
#### Group
  - **Name()** 
  - **Email()**
  - **uniqueID()** field fom jwt that uniquely identifies the group (?jwtSub?)
